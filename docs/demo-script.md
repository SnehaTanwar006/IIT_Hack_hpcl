# Three-Minute Demo Script

1. Open the dashboard.
2. Show the lead queue filtered by Critical priority.
3. Select a highway tender lead.
4. Explain the dossier:
   - source provenance
   - company profile
   - product fit
   - confidence and reason codes
   - score breakdown
   - assigned territory
5. Click Preview alert to show the sandbox WhatsApp-style message.
6. Mark the lead Accepted.
7. Show the analytics summary updating through the API.

Closing line:

> This project converts public B2B buying signals into explainable, routed, actionable sales leads while keeping governance, auditability, and feedback loops visible.
