# Data Governance

## Principles

- Prefer official APIs, RSS feeds, public datasets, and permitted crawling.
- Respect robots.txt, website terms, crawl frequency, and rate limits.
- Log source URL, source type, timestamp, extraction method, and trust score.
- Avoid personal data unless lawful, necessary, and documented.
- Treat WhatsApp alerts as employee notifications only, with opt-in and approved templates.

## Demo Data

The default dataset is synthetic and generated by `scripts/seed_demo_data.py`. It contains 250 labelled signals across tenders, news, company pages, and demo source categories.

## Production Checklist

- Review ToS and robots.txt for every source.
- Add source owner, review date, access method, and allowed crawl frequency.
- Add monitoring for failed crawls, source schema changes, and duplicate rates.
- Store provenance for every extracted fact.
- Mask or omit personal contact data unless it is clearly lawful and needed.
